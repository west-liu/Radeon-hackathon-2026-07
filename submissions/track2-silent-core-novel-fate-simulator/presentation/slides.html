Privacy — All inference local. User novel uploads, chat history, world states never leave the machine.

Innovation — First "Canon Anchor + AI Simulation" engine. No competitor combines IP fidelity with open-ended player agency.

Deployment

One-Command Start on Radeon

# 1. Install ROCm + PyTorch (one-time) pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm7.0 # 2. Start llama.cpp server with Qwen2.5-14B llama-server -m Qwen2.5-14B-Instruct.gguf \ --host 0.0.0.0 --port 8000 \ --ctx-size 8192 --n-gpu-layers 99 # 3. Start Hello E World API cd helloeworld/source pip install -r requirements.txt LLAMA_BASE=http://127.0.0.1:8000/v1 uvicorn main:app --host 0.0.0.0 --port 8080 # 4. Open browser # http://localhost:8080
DockerFull container image available. OfflineRuns without internet after model download.

How the Dual-Agent System Works

sequenceDiagram
    participant User
    participant FG as Foreground Agent
    participant REDIS as Redis Streams
    participant BG as Background Worker
    participant GPU as llama.cpp / W7900
    User->>FG: Player action / choice
    FG->>GPU: Generate scene + options (SSE stream)
    GPU-->>FG: scene_chunk + actions
    FG-->>User: Real-time text + UI update
    FG->>REDIS: Emit world_event (if key_event)
    BG->>REDIS: Consume event (async)
    BG->>GPU: Long-horizon fate simulation
    GPU-->>BG: JSON Patch (state update)
    BG->>REDIS: Apply patch_atomic (optimistic lock)
    BG-->>REDIS: Audit log (admin_only + player_hint)
