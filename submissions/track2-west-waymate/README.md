# Waymate AI Agent — README (Track 2, Agentic AI)
## Project Overview
Waymate is an on-premise multi-modal AI Agent built for AMD Radeon GPU, delivering low-latency LLM reasoning based on ROCm.

## Key Features
- End-to-end Agent workflow running fully on W7900
- Optimized inference with vLLM + ROCm
- Multi-turn task planning & tool calling
